Siswa Kelas 10 SMK Jurusan Teknik Komputer dan Jaringan (TKJ)

Saya adalah seorang siswa kelas 10 SMK jurusan Teknik Komputer dan Jaringan (TKJ) yang memiliki antusiasme dan rasa ingin tahu tinggi terhadap infrastruktur teknologi informasi. Sejak awal jenjang kejuruan, saya berinisiatif aktif mempelajari konfigurasi routing dan switching dasar, inspeksi paket data menggunakan Wireshark, serta bereksperimen dengan skrip Python untuk otomatisasi tugas dan HTML untuk kerangka web. Saya berkomitmen untuk terus mengasah keterampilan praktik, disiplin belajar, dan terbuka untuk kolaborasi belajar bersama rekan sebaya maupun mentor.
